## ✨ Features

- **🏛 Warm Editorial Art Gallery Aesthetic**: Designed with Cormorant Garamond editorial serifs, Plus Jakarta Sans sans-serif typography, subtle terracotta accents, and soft sandstone backgrounds.
- **📱 100% Mobile Responsive & Safe-Area Aware**: Optimized across all screen sizes (iPhone SE, iPhone 13/14/15/16, iPhone Pro Max, and Android). Supports iOS Dynamic Island, Home indicator safe areas (`viewport-fit=cover`), and touch-optimized buttons.
- **🖼 Interactive Simulated Wall Art Preview**: Customers can preview any artwork on a styled living room wall to visualize dimensions and aesthetic fit before ordering.
- **🛍 Dynamic Slide-Over Cart Drawer**: Instant slide-out bag with real-time subtotal calculations, free shipping threshold indicator (`Free Pan-India Delivery on orders > ₹2,999`), and direct WhatsApp / Razorpay checkout integration.
- **🎨 Curated Portfolio Categories**: Dedicated views for **Canvas Paintings** (Krishna, Shiv Shakti, Ganesha, modern abstract) and **Lippan Art** (Annapakshi, Lotus Pichwai, traditional mirror-work hangings).
- **✍️ Custom Commission Studio**: Multi-step bespoke inquiry system allowing clients to request customized artwork sizing, color schemes, and subject matter with WhatsApp handoff.
- **📦 Transit-Safe Packaging Guarantee**: Armored hardboard and reinforced foam edge protection highlighted with trust badges.

## 🚀 Quick Start / WordPress Installation

### Method 1: WordPress Admin Upload (Recommended)
1. Download [evara-art.zip](https://github.com/thepilot2003/evara-art/raw/main/evara-art.zip).
2. Log into your WordPress Dashboard.
3. Navigate to **Appearance → Themes → Add New Theme → Upload Theme**.
4. Choose `evara-art.zip` and click **Install Now**.
5. Click **Activate** (or **Replace active with uploaded** if updating an existing version).

### Method 2: Manual FTP / WP-CLI
```bash
# Clone the repository
git clone https://github.com/thepilot2003/evara-art.git

# Copy theme to WordPress installation
cp -R evara-art/wordpress-theme/evara-art /path/to/wordpress/wp-content/themes/
```
